## DeepSeek opens search and fetch APIs at $0.75 per 1,000 requests

**DeepSeek's new Search and Fetch endpoints return up to 50 ranked web results per call, and cost nothing through Claude Code or Codex until 1 November, its documentation says.**

DeepSeek has published documentation for two web-access APIs aimed at agents and retrieval apps. According to the company's API docs, Search is a POST endpoint at /v1/tools/search, and Fetch, at /v1/tools/fetch, takes a single HTTP or HTTPS address and returns the page title and content as Markdown. Both use a bearer token on api.deepseek.com.

The docs say Search accepts up to 50 results per call and optional page content. Query operators filter by site, language, exact phrase and publication date. Each result carries a relevance score from 0 to 3, a title, a URL, short and long summaries, site information, a publication date and what DeepSeek calls an authority tier. The page describes both tools as read-only.

On price, DeepSeek says each API costs $0.75 per 1,000 successful requests, and only HTTP 200 responses that return results or content are billed. Requests made through DeepSeek Harness, Claude Code or Codex are currently free, the docs say, with per-request billing starting at 00:00 Beijing time on 1 November 2026.

Limits are 5 queries per second per API at the account level, with separate quotas for Search and Fetch and an extra per-domain limit on Fetch. Exceeding either returns HTTP 429. Errors follow the OpenAI-compatible format, and the docs advise retrying only 408, 429 and 5xx responses after a wait.

The documentation does not say which models the tools work with, and nobody outside DeepSeek has published tests of result quality or latency. The page reached the front page of Hacker News, where it had 441 points and 213 comments about 11 hours after it was posted.
