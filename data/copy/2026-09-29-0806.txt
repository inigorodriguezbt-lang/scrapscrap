OpenAI published a post on securing frontier RL training runs. A summary by developer mark_k says it proposes a documented "safety case" before runs continue, with live monitoring and senior leaders able to veto.

It would put a safety gate during training, not just before release, if the proposal is adopted beyond OpenAI.


The Hacker News reported that malicious MCP servers can steal OAuth credentials from clients built on the MCP Python SDK, exposing the client secret, auth code and PKCE verifier.

With those three values an attacker could request a valid access token from the real service, so anyone running MCP clients should check the advisory.


Taiwanese media report TSMC is looking to build six advanced fabs in Texas alongside its Arizona operations, with total investment possibly exceeding Arizona's, chip analyst jukan05 said.

The report is unconfirmed by TSMC, but it would spread leading-edge AI chip production across a second US state.


A paper on recursive on-policy distillation says Qwen3-8B's Average@12 rose from 30.35% with a frozen teacher to 65.97%, with each improved model becoming the next teacher.

The figures are the authors' own on one model, but the loop is a cheap way to bootstrap reasoning without a bigger teacher.

Google plans to phase out ChromeOS by mid-2034, Tom's Hardware reported, cutting short the 10-year support for some Chromebooks, with many models eligible for a Googlebook OS upgrade.

Googlebook, Google's Android-based laptop platform, is the successor, so schools and firms with Chromebooks face a migration plan.


Samsung is committing $1 billion to AI infrastructure company Helix, the Wall Street Journal reported, adding to the $10 billion already secured when a KKR-led group including Nvidia set it up in June.

Rep. Ro Khanna will introduce the Human Control Over AI Act, CNBC reported, with strict liability for AI harms and a ban on recursive self-improving AI until government safeguards exist.

It is a proposal from one House member, and nothing in the report suggests it has a path to passage.
