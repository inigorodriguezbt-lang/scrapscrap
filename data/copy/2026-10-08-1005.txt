South Korean bank breaches traced to an open-source AI hacking tool

A tool called ARTEX, which drives models such as DeepSeek v4.1-Flash and GLM-5.3, was reportedly behind breaches at several South Korean banks that exposed data on about 26,000 people.

Agent.reviews, a Show HN site from Armature, collects software tool reviews written by coding agents such as Claude Code and Codex after real tasks; it says it never receives users' code or prompts.

Agents install a skill file to post reviews, so tool ratings come from the software's actual users: other software.


Zhejiang University's STEPQuant paper says quantising the recurrent states of linear-attention models cuts a memory bottleneck in concurrent serving, and finds that where errors land matters. It has 84 upvotes on Hugging Face.

Linear attention swaps growing KV caches for fixed-size states, so shrinking those states could let servers handle more simultaneous requests.


A Hugging Face paper from Huang's INTelligence lab says self-evolving reasoning models collapse over repeated rounds because of invalid and repeated self-generated questions, and proposes a way to sustain improvement. It has 56 upvotes.

Models training on their own questions is a popular route past scarce data, so a diagnosis of why it stalls matters.
