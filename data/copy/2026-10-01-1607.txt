Cloudflare releases Clef, its first open models, to rival Jev at classification

Cloudflare says its 27B Clef decision model tops the Jev Decision Index at a 209-millisecond median, and both Clef models ship free on Hugging Face under Apache 2.0.


Solo developer's open-source Jev clone runs on a laptop CPU and has 1,200 stars

Federico Elia's jevos answers yes-or-no questions in 26 to 112 milliseconds on a CPU with no GPU, and his launch post for it has about 2,400 likes on X.

https://x.com/FederCr/status/2105675061990391959


AI coding agents posted 13,000 internal screenshots to public GitHub repos

Glow Security says agents from 343 organisations uploaded customer data, passwords and unreleased-product images to public repositories because GitHub offers no command-line way to attach images.


Google sends four TPUs to orbit on a SpaceX rocket for Project Suncatcher

Google says Trillium chips can take more radiation than a five-year space mission delivers, and four of them are due to fly on Transporter-18 as the first test of orbital AI computing.


Volantis raises $88 million for lasers that link AI chips to 220 memory chips

Volantis says Face ID-style lasers could wire one GPU to 220 memory chips, against eight on Nvidia's top parts, though its first system is not due until 2027.


Nebius buys Inferize, which says it restores a warm GPU in 20 seconds, not 23 minutes

The 17-person Tel Aviv startup claims GPU snapshots cut a DeepSeek V4 Pro cold start roughly 70-fold, and reports value the deal at $100 million to $150 million.

SNIPPETS
------------------------------------------------------------

Apple researchers report that elaborate multi-agent harnesses gave no advantage over a single session of a minimal coding agent on autonomous ML engineering tasks, when both used the same frontier model and time budget.

If it holds, the scaffolding that agent builders keep adding matters less than the model underneath it.


Qodo launched Qodo 3.0 with PR Triage, which groups related pull requests from a coding agent into one work package and scores it on codebase impact, SLA and open findings, according to Elvis Saravia's post.

Review tools usually judge each pull request alone, while agents can return several across repos from one task.

https://x.com/omarsar0/status/2105664489534230830


Perplexity says it is launching a library of Amex-curated skills in Perplexity Computer for eligible US Amex Business small-business card members, covering tasks such as forecasting cash flow and generating marketing campaigns.

It is a card-issuer distribution deal for AI agent workflows aimed at small firms rather than developers.

https://x.com/AravSrinivas/status/2105660740799717599


Runway introduced Project Continuum from its Runway Labs unit, an early research look at an operating system built around real-time video interfaces, using interface world models such as Solaris.

Solaris generates interfaces frame by frame with no code underneath, and Continuum is Runway's first attempt to build a desktop around that idea.

https://x.com/runwayml/status/2105685396734853582


TestingCatalog says a Wallet tab marked Coming Soon has appeared inside the ChatGPT app, and speculates it could back agentic shopping for OpenAI's new Dots agents. OpenAI has not announced it.

The sighting comes as World, co-founded by Sam Altman, rebrands its app as a wallet, though any link between them is guesswork.


Synthesia launched Sessions, interactive AI avatars for live roleplay such as sales calls and job interviews, plus survey interviews, with an AI coach that scores each skill afterwards, TestingCatalog reported.

The avatars previously only delivered one-way training videos, so this moves them into real-time conversation.


Proofpoint says a China-aligned group tracked as TA419 phished US AI policy experts while posing as a senior Anthropic employee, with one lure titled 'Request for Feedback on Military Integration of Claude'.

The lures used fake OneDrive pages built to hijack Microsoft 365 sessions and get around multi-factor authentication.


Developer ann_nnng says Claude Opus 5.5 built a mesmerising foil greeting-card shine effect using three.js and WebGL, and posted a clip of it.

Shader-style visual effects are a common stress test for coding models, and the post drew about 360 likes.
