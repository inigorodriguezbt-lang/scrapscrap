Cursor says its SDK agents can now be steered mid-run: run.steer() adds a message to the next turn, and a subagent that is mid-task moves to the background and keeps working.

Steering a running agent rather than restarting it is a small change that matters for long jobs; Cursor's own post is the only source so far.

https://x.com/cursor_ai/status/2107141004482793827


Cognition says Devin now has Dreaming: across sessions it builds a memory graph of how you work and tidies stale records overnight. It is also creating an open standard called Agent Memory Repo.

Persistent agent memory is becoming a product feature, and an open standard could let the memory move between tools; Cognition's claims are untested.

https://x.com/cognition/status/2107165034463867001


Krea says its agent now runs inside Adobe After Effects, where it can create motion graphics, resize video and handle sound and images. Krea says the plug-in is free to try.

It puts a generative agent inside a tool video editors already use; Krea's own video is the only demonstration so far.

https://x.com/krea_ai/status/2107138756507763130


Hobbyist 0xSero says DeepSeek V4.1 Flash now runs on one RTX 3090 plus CPU with a 262k context cache, at about 26 tokens a second decoding. It needs 256GB of RAM and 200GB of NVMe.

A frontier-scale open model on one consumer GPU is the kind of home setup that spreads; the figures are the poster's own and unverified.


Empero AI says it has released Homebrew, an open agent that picks a base model, prepares data, sets safe parameters and trains a model from a plain-language request. Its post had 833 likes when we read it.

Automating model training for non-researchers is a bold claim; nobody outside the company has shown it working yet.
