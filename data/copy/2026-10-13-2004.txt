The omarsar0 account highlights a paper called LongHarness, which reports lifting GLM-5.3-Flash from 4.4% to 61.1% exact match on OfficeQA Pro V2 with the same model, by changing only the agent harness.

If the result holds, it suggests scaffolding around a model can matter as much as the model for long documents.


Artificial Analysis says cost per task for GLM-5.3 at max effort varies about nine times across providers, and it now publishes cache hit rates for each model endpoint it tracks.

Cache hit rates drive agent costs because agents resend their whole history each turn, so the cheapest listed token price can mislead.
