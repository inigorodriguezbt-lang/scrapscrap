## Google Docs and Drive add native markdown editing, 9to5Google reports

**Google says users can open, edit and comment on markdown files in Docs and Drive without converting them, with the rollout starting 5 October and taking up to 15 days.**

Google has begun rolling out native support for markdown files in Google Drive and Google Docs, 9to5Google reported on 5 October. Users can open and edit .md files without changing the format first, and work on them together in real time with comments, according to a Google statement quoted by the outlet. No other outlet has reported it yet.

Drive now shows rendered markdown, with formatted text, clickable links and structured tables, instead of raw syntax, 9to5Google said. Google's statement says people no longer need to write the syntax by hand or convert files to work on them, and that both people and AI agents can take part in the same document. The report does not say how agents get access to the files.

Chandu Thota of Google said markdown has become the common language between humans and AI agents, according to 9to5Google. Developers already use markdown files to hand context and instructions to coding agents. TestingCatalog, which tracks changes to AI products, called it a default way to exchange that material and said the change may simplify a lot, in a post that had 106 likes on Tuesday morning.

https://x.com/testingcatalog/status/2107379242023739810

The rollout started on 5 October and may take up to 15 days to reach every user, according to the report. The feature is on by default for all accounts, including those managed by administrators, so Workspace admins do not have to switch it on. The report does not say whether plan limits apply.

## Amazon adds Z.ai's 753B GLM 5.3 coding model to Bedrock

**Amazon says Z.ai's 753-billion-parameter coding model is open to eligible enterprise customers on Bedrock, and Z.ai claims a 50 percent gain over GLM 5.2 on its own test.**

Amazon Web Services has added GLM 5.3, a model from Z.ai, to Amazon Bedrock, according to an AWS Machine Learning blog post published on 5 October. AWS describes it as a 753-billion-parameter mixture-of-experts model tuned for coding and long-horizon agentic tasks. The post says the weights are also on the Hugging Face Hub. No independent testing of the Bedrock version has been published yet.

Z.ai reports competitive results on coding benchmarks including DeepSWE, Terminal Bench 3.0 and FrontierSWE, the post says. The company also claims a 50 percent improvement over GLM 5.2 on its own internal coding benchmark, and a score of 84.5 on the CyberGym benchmark at release, which it calls leading. All of those are figures from Z.ai, and the post does not publish the underlying scores.

On the platform side, Bedrock offers prompt caching in implicit and explicit modes, and cross-Region inference through US and Global profiles. Customers can pick a Flex, Priority or Standard service tier. The model can be called through either an OpenAI-compatible API or the native Bedrock APIs, which could make it easier to swap into tools that already speak the OpenAI format.

Access is currently limited to eligible enterprise customers, and the post says billing is pay-per-token. It does not give per-token prices, the context window or the licence terms, so buyers would need to check those separately. AWS did not say when the model would reach other customers, and the post does not name the Regions where the profiles route requests.

Read it on the site: https://theaipost.net/story/find-glm-5-3-bedrock/
