## Google folds its Spark agent into the main Gemini app as a Task button

**Gemini's chat screen now has Chat and Task buttons above the prompt box, with Task being Google's Spark agent, 9to5Google reports, and a new Scheduled page for running jobs.**

Google is merging its Spark personal agent into the main Gemini chat app, 9to5Google reported on Monday evening Pacific time. Gemini now shows "Chat" and "Task" buttons above the prompt box, and "Task" is Spark. Google describes it as a "new home for Spark: Start new tasks anytime and keep track of them in your chats," according to the site.

Spark leaves the navigation drawer. In its place, 9to5Google says, a new Scheduled page groups Spark tasks and scheduled actions under Active, Paused, Completed and Suggested. The Recents list becomes one history of chats and tasks, with a filter for All, Ready, Needs attention or In progress, and the account menu's "Gemini Spark Settings" now reads "Task settings."

Engadget's guide, also published on Monday, describes Spark as an agentic assistant Google announced at I/O in May. It runs in the background on a task you give it, works with Docs, Calendar, Slides and Gmail, and can pair with Gemini in Chrome's auto browse for jobs such as booking restaurants. Engadget says it needs a Google AI Pro or Ultra plan and the "Keep activity" setting.

Engadget lists the EEA, Switzerland, the UK and Nigeria as outside the rollout. 9to5Google says the redesign is arriving through a server-side update on Android and was not yet visible on iOS or the web when it published. Engadget also says Google plans to replace Gemini Gems with reusable "skills," which you call by typing a forward slash. Neither outlet gives a date for wider availability, and we have not tested the feature.

## Open-source Rust CAD tool SolidCraft ships an MCP server for agents

**The MIT/Apache-2.0 app has about 1,200 GitHub stars, runs in the browser, and its CLI exposes tools that let an AI agent build and screenshot 3D parts.**

SolidCraft is an open-source parametric 3D CAD application written in pure Rust, posted to Hacker News as a Show HN on Tuesday where it had 25 points when we read it. Its GitHub page calls it "early but usable for simple parts" and shows about 1,200 stars, 117 forks and 760 commits on main.

Its modelling list covers sketches with a constraint solver, extrude, revolve, sweep, loft, fillet, chamfer, shell, holes and threads on an editable timeline. The README also lists assemblies with joints, sheet-metal flanges and flat patterns with DXF export, and STEP, IGES, STL, OBJ and 3MF files. The project says 75 of 76 public reference parts match their expected values, with one tracked bug.

The AI hook is a Model Context Protocol server. According to the README, running `solidcraft-cli mcp` starts it over stdio, headless or attached to the running desktop app, and it offers tools named execute, measure, screenshot, export and undo. The page gives a one-line setup for Claude Code: `claude mcp add solidcraft -- solidcraft-cli mcp`.

It ships as a desktop app for Windows, macOS and Linux, plus a version that runs in the browser with no install. The README says the builds are unsigned, so Windows SmartScreen and macOS may warn. It is dual-licensed MIT or Apache-2.0. Everything above is the maker's own description. We have not run it, and no one else has tested the agent tools that we have seen.

Read it on the site: https://theaipost.net/story/find-solidcraft/
