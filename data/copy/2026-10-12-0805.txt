Researchers teach a Unitree G1 humanoid to catch thrown boxes from camera alone

A University of Washington-led paper says its Reflex controller let a Unitree G1 catch human-thrown boxes 65 percent of the time at 2.5 metres, using only an onboard depth camera.


Kling team says new diffusion training method cuts GPU hours 12-fold

KlingAI researchers say DiffusionART matched rival reinforcement-learning methods on a 13B video model with about 12 times fewer GPU hours, and removes the need to tune EMA.


Palantir CTO says Pentagon already replaced Anthropic

Palantir's Shyam Sankar told CBS the Pentagon's drop of Anthropic had no operational impact because it "has already been replaced", and that AI makers own the liability for defective models.

SNIPPETS
------------------------------------------------------------

OpenAI's GPT-6.1 Sol now defaults to a 500K-token context window in Codex and ChatGPT Work, up from 272K, at no extra charge, according to developer-relations posts on X.

Fewer compactions on long agent runs means less mid-task context loss, which is the main complaint about long Codex sessions.


Atticus, a Show HN project, is an MIT-licensed hold-to-talk voice assistant for macOS 26 that routes requests through Claude Code on a Pro or Max plan; it had 23 GitHub stars.

It needs no API key and handles simple commands locally, with the README estimating about 0.14 cents of plan usage per request.


EmbodiedCLBench, from Peking University, tests whether embodied agents learn from experience: 268 household tasks where zero-shot agents solve about 50 percent of basic and 10 percent of advanced ones.

The authors say one learning sample lifts advanced success to 28-40 percent but more samples add little, so agents still use experience poorly.


AWS and HSBC researchers say their Double Ratchet method evolves an agent's grader from 10 labeled examples and kept 88 to 110 percent of the gain that ground-truth graders gave, per Rohan Paul's summary.

Self-improving agent loops usually need a human-written grader, so removing that step could make them cheaper to set up.
