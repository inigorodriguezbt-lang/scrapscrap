AMD says ROCm 10.1 is out, with faster storage and I/O, new programming models, expanded virtualisation, more developer tools and continued improvements to compilers, libraries and AI frameworks.

ROCm is the software stack that decides whether AI code runs well on AMD's GPUs, so each release matters to anyone avoiding Nvidia.

Perplexity is moving from search to publishing open models, and the new benchmark gives it a leaderboard to point at.


Mitra's AI assistant can now take over chats using learned user context, and Mitra Link lets one person's assistant schedule directly with another's, TestingCatalog reports. Real estate agents are using it for showings.

OpenChart, a free macOS trading app on GitHub, lets Claude, Codex or Gemini run research and build alerts from plain-language descriptions. The Show HN post had 29 points and the repo 59 stars.
