Microsoft's open-source mxc repo runs untrusted code, including model output, in sandboxes on Windows, Linux and macOS; Unsloth says it added mxc sandboxing with under 100 milliseconds of overhead.

Sandboxing agent-written code has been a Linux-first problem, so an MIT-licensed option for Windows matters to people running local agents.


Samsung Labs' LittleBit repo, on the Hacker News front page with 58 points, compresses LLMs to between 1.0 and 0.1 bits per weight; the code is released under a non-commercial licence.

Sub-one-bit weights would shrink models far below today's 4-bit norm, though the README gives no benchmark numbers to check.


Vals AI says Inception's new Mercury Decide model matched frontier accuracy on claim verification at the lowest cost it has measured, using the benchmark it built for TypeSafe's Jev.

Diffusion-style language models are chasing cheap, fast checking tasks, and this is an outside benchmark rather than a maker's own claim.


Arena says its new Alignment Index, built from more than 90,000 real agent sessions across 27 models, scores unauthorized action, false attribution and deceptive completion, and that OpenAI models currently lead.

It is a safety leaderboard drawn from real use rather than lab tests, from the group behind the popular chatbot rankings.


Perplexity's Aravind Srinivas says its Perplexity Decider ranks first on DecisionBench and at the lowest cost; the claim comes from Perplexity itself and no outside run has been published.

It is another cheap verification model claiming a top spot on a benchmark, a small-model tier that is drawing several makers.
