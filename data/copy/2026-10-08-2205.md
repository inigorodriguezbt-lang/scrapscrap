## Anthropic will scan opted-in open-source projects for bugs, free

**Anthropic says its OSS Scanner will use its strongest models to run periodic, no-cost vulnerability scans on opted-in open-source projects, with a proof-of-concept and suggested fix in each report.**

Anthropic announced the Anthropic Cyber Mission on Thursday, which it describes as a new effort to secure critical infrastructure and open-source software. Its news page dates the post to 8 October. The company's account on X said the work will take time, and that the mission will expand and change as the company learns what works.

https://x.com/AnthropicAI/status/2108302539498414208

The open-source half is a service called OSS Scanner. Anthropic says it will use its frontier models to periodically scan open-source projects that opt in, at no cost. According to the company, each report will include a proof-of-concept, an explanation of the flaw and a suggested fix. Projects that do not opt in are not covered.

The Verge, which covered the launch, quoted Anthropic as promising opted-in projects "thorough, periodic security scans by our strongest models at no cost". The outlet said that could mean maintainers hear about possible security issues sooner. Anthropic's announcement does not say how many projects will be scanned, or how maintainers will be told.

The second half is a Critical Infrastructure Defense Program. Anthropic says it will bring frontier Claude models, on-site engineers and its latest research to operators of systems such as power grids and water systems, and to their security and manufacturing suppliers. We could not open the full announcement, so the partner list and terms are unconfirmed here.

All of this is Anthropic's own account of its plans, and no independent reviewer has tested the scanner. Whether maintainers find the reports accurate or overwhelming is the open question. The programme follows Anthropic's expanded Cyber Verification Program, which it announced on 6 October.

## Developer squeezes an AI chat agent onto a Nokia 110 feature phone

**A developer reverse-engineered a Nokia 110 4G's firmware and turned its Calculator app into a DeepSeek chat client that, they say, sets alarms, places calls and flips the torch.**

A developer who posts as anupray95 says they put an AI agent on a Nokia 110 4G, a number-pad feature phone with about 48MB of memory. The project was posted to Hacker News as a Show HN and had 22 points when we read it. The repository had one star.

According to the README, the author reverse-engineered the phone's firmware and modified the Calculator app into a chat app. You type on the number pad. Messages go to the DeepSeek chat API, the README says, which uses tool calls to trigger actions on the handset. The page does not name a specific DeepSeek model.

https://www.youtube.com/watch?v=i5Ce53QkMkU

The author lists what the agent can do: answer questions using SIM data, report the battery percentage, turn the torch on and off, start calls and set alarms. To fit the memory, the README says, the project uses a simplified custom agent, smaller builds, compressed payloads and reused buffers. The author also says they used OpenAI Codex to help build it.

There are limits. The README says the program is loaded into RAM from a computer and must be reloaded after a restart or power-off, and that installing it permanently is unresolved. Once loaded, it can run unplugged over mobile data. The author is not publishing the source, saying sensitive data is spread through the project.

With no code released, the claims cannot be checked beyond the author's demo video, linked from the README. Nobody else has reproduced the work, as far as we can tell. It is a stunt rather than a product, but it shows how little hardware a cloud-backed agent needs on the device.

Read it on the site: https://theaipost.net/story/find-nokia-110-ai-agent/
