Developer splits a language model across seven microcontrollers

An open-source project runs a compressed 0.5-billion-parameter model across a cluster of ESP32-S3 chips wired together, with one board handling tokenization and six others splitting the transformer layers.


Modal Labs nears $750 million round at $15.75 billion valuation

TechCrunch reported the inference infrastructure startup's valuation has more than tripled in four months, as rival providers Baseten, Fireworks and Fal raise at similarly steep multiples.

ByteDance published TraceDance, an open-source system that turns real agent deployment traces into targeted benchmarks for one undesirable behavior, instead of a fixed test suite.

It gives developers a way to test for the exact failure they saw in production rather than hoping a generic benchmark catches it.


A paper posted as HexaFuture's 'Physical Coding' has robots write and revise code as their own control policy, arguing that vision-action models fail on small layout changes because their logic stays implicit in raw actions.

The approach reframes robot control as a programming problem, and the authors posted code on GitHub for anyone to test the claim.


A paper posted to GitHub as thu-nics/TaH studies adaptive looped transformers, which reuse the same layers instead of adding new ones, to see whether looping helps accuracy as a model thinks longer at test time.

Reusing layers is a cheaper way to add computation than growing a model, so whether it scales the same way matters to anyone training on a budget.


Developer Jon Clegg built Pac-Bench, a leaderboard that scores AI models on writing a playable Pac-Man game from one prompt, tracking cost, time and token count per entry.

It turns one-shot coding claims into a public, repeatable scoreboard, though no model has posted a result on it yet.


Australian developer Goodman Group withdrew its application for a 24-hour data center on Sydney's north shore after community pushback, Bloomberg said.

The reversal shows AI-driven data center construction is running into the same local opposition that has stalled projects in the US and Europe.


Nvidia is turning to insurers to help spread the financial risk of its AI data center build-out, the Financial Times said, calling it a new route for Wall Street money into the AI boom.

Insurance-backed financing could let Nvidia's partners raise debt against AI infrastructure without Nvidia holding all the downside itself.


OpenAI is testing agents internally named 'Dots', an evolved, customer-facing version of its 'aeons' custom agents, according to new app strings spotted by TestingCatalog.

The strings describe an agent you can text, call or message on Slack, suggesting OpenAI is building a broader agent product it has not announced.


Instinct, a personal AI agent startup founded by Noah Shinn, is growing about 10% a day through invite-only access, Shinn said, competing against Big Tech rivals with no distribution advantage.

Shinn pointed to the compute crunch behind that growth rate and how fast users trust an agent with financial tasks as the open questions.
