Harvard physicist Matthew Schwartz says his open-source BootLoops harness helped Claude produce 36 manuscripts across 18 fields in three months with 19 co-authors, and warns the model often declares victory too early.

Schwartz, a visiting researcher at Anthropic, describes the code and results in a guest post on Anthropic's site; the source code is on GitHub.

It is one developer's opinion, not a benchmark, but it speaks to a live argument about how coding agents should keep context between sessions.

A Meta paper called RankEvolve runs Claude Code and Codex as separate nodes that review each other's changes; Meta authors say the pair reach 62.5% execution accuracy against 45.8% for the best single product.

The paper targets silent bugs, such as leaked eval data, that can invalidate hours of agent-run ML experiments; dair_ai's summary is the only account we read.


A CMU paper on harness learning trains a 4-billion-parameter proposer with reinforcement learning to edit an agent's harness code, and omarsar0 says it beats its 35B teacher at single-step revision on Reasoning Gym.

The solver model never changes, so the gains come from improving the surrounding code rather than the weights; the figure comes from the paper as summarised by omarsar0.
