## Llmspeed shows how fast a local LLM runs on a GPU you lack

**A free Show HN site streams text at the estimated speed of 29 devices, from an RTX 3090 to a 512 GB Mac Studio, though some figures are projections rather than benchmarks.**

Llmspeed, a Show HN project that reached 46 points and 15 comments on Hacker News, simulates how fast a local language model would feel on hardware you may not own. Its tagline promises to let you feel local LLM speed before buying. Pick a device and a model, and the page streams text at the estimated speed, wait for the first token included, per its README.

The page lists about 29 devices and 15 models. Hardware includes the RTX 3090, RTX 4090 and RTX 5090, AMD's Ryzen AI Max+ 395 with 128 GB, a Mac Studio M3 Ultra with 512 GB, Nvidia's DGX Spark, a CPU-only Ryzen 9950X, and cloud cards such as the H100 and H200. Models include Qwen 3.6 and 3.8 27B, GPT-OSS 20B and 120B, Gemma 4 and DeepSeek V4 Flash.

The numbers come from two places, the README says. Measured figures are gathered from community benchmarks on r/LocalLLaMA, localscore.ai and llama.cpp discussions, and contributors can add more through pull requests. Setups with no benchmark get estimates labelled "Derived", interpolated from similar hardware, or "Projected", calculated from specifications.

The README explains the method: generation speed is treated as limited by memory bandwidth, with each token reading the active weights once, and only active parameters counted for mixture-of-experts models. Prompt processing is treated as limited by compute. Contributed benchmarks use llama.cpp's tg128 and pp512 results.

The caveats are real. The main page does not say which figures are measured and which are projected, and estimates are for a short prompt on a single device. The code is MIT-licensed, but the repository had only 18 stars when read on October 17, and nobody else has independently tested the predictions.

Read it on the site: https://theaipost.net/story/find-llmspeed-local-llm-speed-simulator/
