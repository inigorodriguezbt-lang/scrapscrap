Google folds its Spark agent into the main Gemini app as a Task button

Gemini's chat screen now has Chat and Task buttons above the prompt box, with Task being Google's Spark agent, 9to5Google reports, and a new Scheduled page for running jobs.


Open-source Rust CAD tool SolidCraft ships an MCP server for agents

The MIT/Apache-2.0 app has about 1,200 GitHub stars, runs in the browser, and its CLI exposes tools that let an AI agent build and screenshot 3D parts.

TestingCatalog reports that Google's Gemini account confirmed Gemini 4 Argon arrives today for Ultra subscribers; the model was announced September 30 and had been limited to trusted testers.

Argon has been closed-beta only, so this would be the first consumer access; the report is unconfirmed until Google's own rollout notes appear.


Reuters reports, per a Techmeme summary, that Character.AI filed for Chapter 11 in the US and agreed to sell some assets to Disney for $20 million while it keeps operating.

Disney sent the chatbot maker a cease-and-desist letter over its characters in September 2025, so the buyer is a former adversary.


TestingCatalog says a unified X Subscription is rolling out across Grok, Cursor and X Premium, with Plus at $8 a month and Ultra at $200.

The post quotes the plan text saying each tier gives more usage of the company's own models than the plan it replaces; rollout is gradual and unconfirmed.


Theo says he gave Opus 5.5, GPT-6.1 Sol and Meta's Muse Wonder Full the same bug: Opus found the root cause and filed a PR, while GPT-6.1 Sol crashed on a question tool before fixing it.

It is one developer's anecdote, not a benchmark, but it is an early head-to-head with Meta's new model from a widely followed coder.
