## Pocketty puts an iPhone SSH terminal in front of blocked coding agents

**A new iPhone and iPad app pings you when a coding agent is stuck and opens a live terminal to answer it, for a one-off $99 launch price.**

Pocketty is an iPhone and iPad SSH terminal built around herdr, a tool for running AI coding agents, according to the app's own page. It sends an optional alert when an agent is blocked or finished, and lets the developer answer from the phone. It reached the Show HN board on Thursday, where it had 23 points and nine comments when we read it.

The developer says tapping an alert opens the agent's herdr pane over SSH in a real terminal, with Return, Esc, Ctrl and arrow keys. The page also lists live agent state across workspaces, diffs by agent turn, session or uncommitted change, a file browser and previews of localhost dev servers through the SSH connection. It says it works as a plain SSH client without herdr, and supports tmux and zellij.

Setup, the page says, means installing a small daemon on a Mac or Linux machine and pairing the phone with a six-digit code. Tailscale is recommended for reaching the computer from anywhere, though any reachable SSH server works. The page says terminal traffic goes directly between phone and computer, and that notifications are sealed on the computer with the phone's key and relayed through a Cloudflare Worker and Apple Push.

Pocketty says the relay cannot read or store those notifications, a claim we could not verify. The app is free for 14 days with all features, then costs $99 once, a launch price the page says will rise to $129, with no subscription, account or ads. Android is not available yet. The page also compares itself with a rival app, Moshi, and those comparisons are the developer's own. Nobody else has tested the app yet.

## Open-source Jevman benchmark has AI models play Pac-Man against the ghosts

**Opper AI's Jevman asks a model for a direction probability at every junction, with two seconds to answer, across 100 recorded games per model.**

Opper AI has released Jevman, an open-source benchmark in which language and decision models play the arcade game Pac-Man, according to the project's page. It appeared on Show HN on Thursday and had 31 points and five comments when we read it. The page says six models have each played 100 games against the classic ghosts.

The company says the model receives the maze, the pellets and the ghost positions at each junction, and returns a probability for each direction. Answers must arrive within two seconds, or a simple backup rule makes the move. A game ends when Pac-Man loses three lives, or after five minutes, and the page says the longest game so far lasted two minutes 24 seconds.

Rankings use the mean score with a 95 per cent margin of error, and models within each other's margin are marked as tied. The page says every game is recorded and replays exactly, so results can be checked. We could not read the leaderboard values or the names of the six models from the page, so the scores are not reported here.

The project is licensed under AGPL-3.0. The company says any model behind an HTTP endpoint can be added by pull request, with continuous integration replaying the games to verify the score. Models on Opper or other public APIs can be requested through a GitHub issue. The page offers Play vs AI and Watch sections. No independent group has run the benchmark yet.

Read it on the site: https://theaipost.net/story/find-jevman-pacman-benchmark/
